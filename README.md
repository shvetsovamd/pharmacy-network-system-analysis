# Проектирование системы обработки заказов для онлайн-сети аптек

Комплексный проект по системному анализу и моделированию бизнес-процессов (BPM) для распределенной сети интернет-аптек.

## Цель проекта
Автоматизация контура обработки заказов: от момента сборки корзины пользователем на сайте/в приложении до выдачи заказа в аптеке или передачи курьеру, с учетом контроля остатков на складах и специфики учета лекарственных средств (рецептурный отпуск, сроки годности).

## Стек технологий и нотаций
*   **Методологии анализа:** IDEF0, IDEF3, DFD
*   **Проектирование ПО:** UML (Use Case, Sequence, Class diagrams)
